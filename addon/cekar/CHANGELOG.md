# Changelog

## 0.1.4

- Expense rows show a different icon colour per kind (split equally, for someone, personal, exact, payment, trip).
- Pages for something that no longer exists show a plain message with a button back to Lists instead of raw data; opening or saving something that was just deleted shows a short notice and refreshes.
- Settle up warns again when a changed amount is still more than what is owed.
- Name and title fields stop at their maximum length; the "for" button is hidden when there is only one member; "Shared" is used in the edit dialog too; small layout fixes (Who are you?, Done shopping, trip row title).
- The hint about people appearing in Settings shows only inside Home Assistant.
- Docs: repository and issue-tracker links in the add-on docs; Settings page docs updated.

## 0.1.3

- Small GitHub and Documentation icon links at the bottom of Settings.

## 0.1.2

- If someone deletes the list you are viewing, you are taken to the start list with a notice.
- Settings explains that people appear once they have opened Cekar.

## 0.1.1

- List chips (counts, new and deleted lists) update by polling.
- Inside Home Assistant on a phone the app's own header is hidden; Settings shows who you are signed in as.
- Removed the ignored ingress_panel key; switch on Show in sidebar after installing.

## 0.1.0

- First test release: shared lists, expenses, balances, settle up, trips and Settings.
- Add-on icon and logo.
- Documentation for installation, options and the optional API port.

## 0.0.1

- Initial skeleton.
