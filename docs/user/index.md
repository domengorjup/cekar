# Overview

Cekar is a small web app for one household. It looks like part of Home Assistant when used as an add-on, and works on phones and desktops.

![Shopping list](../assets/screenshots/lists-groceries-desktop-light.png)

## What it does

- Keeps several **shopping lists**. Everyone sees changes from the others within a few seconds.
- Records **shared expenses** in euros and works out who owes whom.
- Lets you **settle up** in full or in part.
- Turns a finished shopping trip into expenses with **Done shopping**.

## What it does not do

One household only, euros only, English only. There is no receipt photo, no categories and no CSV export yet.

## Screen layout

The top bar has three tabs: **Lists**, **Expenses** and **Settings**. On phones the tabs move to a bottom bar.
